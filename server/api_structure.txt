# Book Reading Club API Structure

This file reflects the rental system now implemented in the server app.

Base notes:
- Base API prefix: `/api`
- Auth uses the existing cookie/JWT session flow
- Error shape: `{ "error": "Human readable message" }`

## Books - `/api/books`

### `GET /api/books`
Public.

Query params:
- `page`
- `limit`
- `category`
- `available`
- `search`
- `sortBy` = `pricePerDay | pricePerWeek | pricePerMonth | averageRating | title`
- `order` = `asc | desc`

Book list fields:
- `_id`
- `title`
- `author`
- `category`
- `pricePerDay`
- `pricePerWeek`
- `pricePerMonth`
- `depositAmount`
- `replacementCost`
- `isAvailable`
- `unavailabilityReason`
- `averageRating`
- `image`

### `GET /api/books/:id`
Public.

Full book fields include:
- `pricePerDay`
- `pricePerWeek`
- `pricePerMonth`
- `depositAmount`
- `replacementCost`
- `isAvailable`
- `unavailabilityReason`

### `GET /api/listings/my`
Requires auth.

Returns the current user’s active and inactive listings, excluding removed listings.

### `POST /api/listings`
Requires auth.

Request:
```json
{
  "title": "Tokyo Drift",
  "author": "Kei Watanabe",
  "description": "A fast-paced novel set in modern Tokyo.",
  "category": "Fiction",
  "image": "https://example.com/cover.jpg",
  "rentPrice": 299
}
```

Response:
```json
{
  "message": "Book listing created successfully",
  "listing": {
    "_id": "...",
    "listedBy": "...",
    "listingStatus": "active",
    "title": "Tokyo Drift",
    "author": "Kei Watanabe",
    "description": "A fast-paced novel set in modern Tokyo.",
    "category": "Fiction",
    "rentPrice": 299,
    "pricePerDay": 3.3,
    "depositAmount": 299,
    "replacementCost": 299,
    "isAvailable": true,
    "unavailabilityReason": "none"
  }
}
```

### `PUT /api/listings/:id`
Requires auth.

Updates a listing owned by the authenticated user using the same request shape as create.

### `DELETE /api/listings/:id`
Requires auth.

Marks a listing as removed so it no longer appears in public book queries.

## Rentals - `/api/rentals`

### `GET /api/rentals/preview`
Requires auth.

Query:
```json
{
  "bookId": "...",
  "rentalType": "daily",
  "rentalDuration": 7
}
```

Response:
```json
{
  "allowed": true,
  "message": "",
  "pricing": {
    "totalRentPrice": 280,
    "depositAmount": 500,
    "total": 780
  }
}
```

### `POST /api/rentals/create`
Requires auth.

Request:
```json
{
  "bookId": "...",
  "rentalType": "daily",
  "rentalDuration": 7
}
```

Response:
```json
{
  "message": "Book rented successfully",
  "rental": {
    "_id": "...",
    "book": "...",
    "rentalType": "daily",
    "rentalDuration": 7,
    "totalRentPrice": 280,
    "depositAmount": 500,
    "rentedAt": "...",
    "dueDate": "...",
    "status": "active",
    "paymentStatus": "paid",
    "paymentAmount": 780,
    "paymentCurrency": "INR"
  },
  "payment": {
    "chargedAmount": 780
  }
}
```

### `GET /api/rentals/my-rentals`
Requires auth.

Response:
```json
{
  "total": 2,
  "alerts": [
    {
      "rentalId": "...",
      "type": "due_soon",
      "message": "Due in 2 days"
    }
  ],
  "rentals": []
}
```

### `GET /api/rentals/all`
Requires admin.

Returns all rentals for return processing/admin reporting.

## Cron - `/api/cron`

### `POST /api/cron/check-overdue`
Requires admin.

Runs the daily overdue processor:
- calculates overdue days
- updates rental overdue charges and status

## Admin - `/api/admin`

### `GET /api/admin/users`
Requires admin.

Query:
- `search`

Response fields:
- `_id`
- `name`
- `email`
- `role`
- `isSuspended`

## Restriction Rules

Block new rentals when:
- `isSuspended === true`

Show reasons such as:
 - `Your account is suspended`
