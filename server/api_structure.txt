# Book Reading Club API Structure

This file reflects the rental + wallet system now implemented in the server app.

Base notes:
- Base API prefix: `/api`
- Auth uses the existing cookie/JWT session flow
- Error shape: `{ "error": "Human readable message" }`

## Books - `/api/books`

### `GET /api/books`
Public.

Query params:
- `page`
- `limit`
- `category`
- `available`
- `search`
- `sortBy` = `pricePerDay | pricePerWeek | pricePerMonth | averageRating | title`
- `order` = `asc | desc`

Book list fields:
- `_id`
- `title`
- `author`
- `category`
- `pricePerDay`
- `pricePerWeek`
- `pricePerMonth`
- `depositAmount`
- `replacementCost`
- `isAvailable`
- `unavailabilityReason`
- `averageRating`
- `image`

### `GET /api/books/:id`
Public.

Full book fields include:
- `pricePerDay`
- `pricePerWeek`
- `pricePerMonth`
- `depositAmount`
- `replacementCost`
- `isAvailable`
- `unavailabilityReason`

## Rentals - `/api/rentals`

### `GET /api/rentals/preview`
Requires auth.

Query:
```json
{
  "bookId": "...",
  "rentalType": "daily",
  "rentalDuration": 7
}
```

Response:
```json
{
  "allowed": true,
  "message": "",
  "pricing": {
    "rentalFee": 280,
    "depositAmount": 500,
    "total": 780,
    "walletBalance": 1200,
    "walletAfter": 420
  }
}
```

### `POST /api/rentals/create`
Requires auth.

Request:
```json
{
  "bookId": "...",
  "rentalType": "daily",
  "rentalDuration": 7
}
```

Response:
```json
{
  "message": "Book rented successfully",
  "rental": {
    "_id": "...",
    "book": "...",
    "rentalType": "daily",
    "rentalDuration": 7,
    "rentalFee": 280,
    "depositAmount": 500,
    "rentedAt": "...",
    "dueDate": "...",
    "status": "active"
  },
  "wallet": {
    "chargedAmount": 780,
    "balance": 420
  }
}
```

### `GET /api/rentals/my-rentals`
Requires auth.

Response:
```json
{
  "total": 2,
  "alerts": [
    {
      "rentalId": "...",
      "type": "due_soon",
      "message": "Due in 2 days"
    }
  ],
  "wallet": {
    "balance": 420,
    "pendingDuesTotal": 0
  },
  "rentals": []
}
```

### `GET /api/rentals/all`
Requires admin.

Returns all rentals for return processing/admin reporting.

### `POST /api/rentals/:id/return`
Requires admin.

Request:
```json
{
  "condition": "minor",
  "damagePercentage": 0.25,
  "adminNote": "Corner tear"
}
```

Conditions:
- `good`
- `minor`
- `major`
- `lost`

Response:
```json
{
  "message": "Return processed successfully",
  "returnSummary": {
    "rentalId": "...",
    "returnedAt": "...",
    "status": "returned",
    "condition": "minor",
    "damageCharge": 300,
    "depositRefund": 200,
    "extraWalletDeduction": 0,
    "pendingDue": null
  }
}
```

Requires auth.

  "balance": 420,
  "pendingDuesTotal": 120,
  "pendingDues": []

```

Requires auth.

      "_id": "...",
      "type": "debit",
      "amount": 780,
      "reason": "rental_fee",

```

### `POST /api/wallet/topup`
Requires admin.

Request:
```json
{
  "userId": "...",
  "amount": 1000,
  "note": "Manual admin top-up"
}
```

## Cron - `/api/cron`

### `POST /api/cron/check-overdue`
Requires admin.

Runs the daily overdue processor:
- calculates overdue days
- deducts daily overdue charges from wallet
- creates pending dues if wallet is short
- flags rentals/accounts after 7 overdue days

## Restriction Rules

Block new rentals when:
- wallet balance is lower than rental total
- `pendingDuesTotal > 0`
- `isFlagged === true`
- `isSuspended === true`

Show reasons such as:
- `Insufficient balance — please top up your wallet`
- `You have pending dues of ₹X — clear dues to rent again`
