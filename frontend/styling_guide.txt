## What Changes Immediately

In `index.css` or `main.jsx`, import in this order:

```css
@import './styles/tokens.css';
@import './styles/global.css';
```

Then delete every hardcoded color (`#333`, `#fff`, `rgba(0,0,0,0.1)`) from every component CSS file and replace with tokens. Delete every hardcoded pixel value that isn't a multiple of 4 or 8. Remove all `box-shadow` declarations except `var(--shadow-sm)` and `var(--shadow-md)`. Remove all font-weight 700 from body text — only headings use 600 maximum. Remove all `font-size` values that aren't in the type scale.

The result is a system where every page feels like it belongs to the same product, spacing is consistent and generous, and the hierarchy is immediately readable without decorative noise.
